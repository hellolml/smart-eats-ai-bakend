# Curate Candidates Reference

对提取出的地点进行去重、分类、评分和用户确认。

评分维度：

- 热度：来源提及次数和推荐强度
- 偏好匹配：是否符合用户偏好
- 时间适配：季节、营业时间、行程天数
- 预算适配：费用是否符合预算

处理规则：

- 名称相似且地理位置接近的地点合并。
- 多个来源明确避雷的地点移入排除区。
- 用户手动补充地点必须保留并提高优先级。
- POI 搜索验证用 `travel_search_poi`。

用户确认：

- 按景点、住宿、美食、已排除地点分组展示。
- 每次用户删除或补充后重新展示候选列表。
- 用户明确确认后才能进入行程生成。
