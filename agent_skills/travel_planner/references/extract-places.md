# Extract Places Reference

从攻略 URL、粘贴原文或图片 OCR 内容中提取可用于行程规划的 POI 候选。

输入字段：

- `urls`: 攻略链接列表
- `raw_texts`: 用户粘贴的攻略正文
- `images`: 用户上传的攻略截图路径或 URL
- `destination`: 目的地城市或区域
- `preferences`: 用户偏好

输出应包含：

- 来源解析状态
- 地点名称、类别、地址、原文片段
- 高德搜索关键词 `amap_poi_keyword`
- 推荐理由、避雷信息、预计停留时长
- 关联美食、住宿和附近推荐

约束：

- 只基于用户提供内容提取地点。
- URL 获取失败时跳过并提示用户改用截图或粘贴原文。
- 不要凭常识补充攻略中未出现的地点。
